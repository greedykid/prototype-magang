### [Temuan B-03] [P1 / Kompatibilitas Database] Raw SQL Operator GLOB Khusus SQLite pada Model LPK
- **Status:** **TERSELESAIKAN (RESOLVED)**
- **Lokasi File:** [`app/Models/Lpk.php`](file:///home/rizkiarbi/prototype-magang/app/Models/Lpk.php)
- **Implementasi Perbaikan:**
  Klausa `whereRaw` pada fungsi penomoran registrasi kini memeriksa driver database aktif via `DB::getDriverName()`:
  - SQLite: `no_reg GLOB '[0-9]*'`
  - MySQL / MariaDB: `no_reg REGEXP '^[0-9]'`
  - PostgreSQL: `no_reg ~ '^[0-9]'`
  - Fallback driver lain: `CAST(no_reg AS INTEGER) > 0`
  Hal ini menjamin kompatibilitas penuh ketika aplikasi dipindahkan ke lingkungan server MySQL atau PostgreSQL.
